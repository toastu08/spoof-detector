## Question

Can the exact first-iteration training set be recovered from the ASVspoof 2019 LA
source audio and the recipe recorded in `1.1_data_prep-train-old.ipynb`?

**Answer:** yes. The seed-42 sampling reproduces the surviving notebook output
row-for-row, and all 10,080 regenerated images are pixel-identical to the
corresponding images in the later full-split export.

## Recipe

The canonical sampling code is `1.1_data_prep-train-old.ipynb`, cell index 11
(`execution_count: 9`):

```python
df_real = df_train[df_train['label'] == 0]
df_fake = df_train[df_train['label'] == 1]

df_fake_sampled = df_fake.sample(n=7500, random_state=42)

df_train_balanced = pd.concat([df_real, df_fake_sampled])
df_train_balanced = df_train_balanced.sample(frac=1, random_state=42).reset_index(drop=True)
```

`pd.read_csv` preserves protocol row order as the dataframe index, so the
original `protocol_row` survives even though the notebook drops
`audio_file_name`. The second shuffle defines the exported
`sample_<sample_index>.png` filenames. The train protocol is block-sorted:
rows `0–2579` are bonafide, rows `2580–25379` are spoof.

Preprocessing is unchanged from the verified contract (AGENTS.md §4.2):

1. `librosa.load(path, sr=16000)`
2. `librosa.util.fix_length(data=y, size=64000)`
3. `librosa.feature.melspectrogram(y=y, sr=16000, n_mels=128)`
4. `librosa.power_to_db(mel_spec, ref=np.max)`
5. `plt.imsave(path, spec_db, cmap='magma', origin='lower')`
6. output: 126 × 128 RGBA PNG

### Anchor evidence

The 20 anchors in `src/spoof_detection/sampling.py` come from two surviving
outputs of the old notebook:

- the final 10,080-row dataframe display (head and tail), and
- a seedless `sample(10)` of the balanced frame whose row indices are fixed by
  the seed-42 shuffle.

Both the head/tail rows and the index→attribute pairs match exactly. This is
strong evidence that the current pandas/numpy RNG path reproduces the original
selection, not merely the same class counts.

```bash

uv run python -m unittest discover -s tests -p "test_*.py" -v
```

The full run took about 3 minutes on the local machine (≈2:46 rendering,
≈0:16 parity, plus hashing) and wrote 257 MB. The script refuses to overwrite
a non-empty output directory without `--force`, and `--force` can only remove
directories inside `data/derived/`.

## Limitations

1. **Original PNGs are lost.** The first-iteration 10,080 PNGs no longer exist.
   Pixel parity is verified against the later full-split export produced by the
   same preprocessing function, not against the lost originals. Membership and
   ordering are proven independently by the 20 notebook anchors.
2. **PNG byte hashes are environment-dependent.** `sha256_png` hashes the PNG
   file bytes; matplotlib/zlib changes could alter them even with identical
   pixels. The decoded pixel comparison (`pixel_parity.csv`) is the
   authoritative image check.
3. **Manifest provenance is row-based.** The protocol has no stable file ID in
   the exported metadata, so the manifest must be joined by `protocol_row` or
   `audio_file_name`, never by image filename alone.
4. **No model evaluation here.** This experiment only establishes the dataset.
   EER/AUC and threshold behaviour remain Phase 0 work (E0.2–E0.3).
