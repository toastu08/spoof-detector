## Summary

<!-- TODO: fill after the run. -->

Three image conditions (`full`, `speech_only`, `nonspeech_only`), three feature
probes (`duration_only`, `metadata_system_id`, `metadata_speaker_id`) and one
attribution analysis (`silence_trim`) are used to test whether the frozen
backbone detects spoofing from speech content or from silence/noise, duration,
or metadata shortcuts.

## Metric contract (AGENTS.md G4)

| Split | Role | Attack subset | Samples (bonafide / spoof) |
|---|---|---|---|
| train | fitted head/classifier only | A01–A06 | 10,080 (2,580 / 7,500) |
| dev | model selection | A01–A06 | 24,844 (2,548 / 22,296) |
| eval | clean estimate | A07–A19 | 71,237 (7,355 / 63,882) |

- **EER and AUC are threshold-free.** The primary comparison is eval EER/AUC.
- The fixed `p >= 0.5` operating point is reported descriptively (`FPR@0.5`,
  spoof recall@0.5). It is not tuned.
- Eval was never used for training, early stopping, or selection.

## Method and provenance

Each condition shares the same 16 kHz / 4 s / 128-band mel contract; only the
mask changes. A frame is speech when its RMS energy is within 30 dB of the clip's
per-frame energy peak. Masked frames are set to the colormap bottom after
min-max normalisation. `full` is the unmodified control.

Reproduce:

```bash
make e1-4-export     # ~318k PNGs into data/derived/e1_4_shortcuts/ (~8 GB)
make e1-4-train      # 3 image probes + 3 feature probes into Models/Iteration1/e_1_4/
make e1-4-evaluate   # harness output into reports/phase1/e1_4_shortcuts/runs/
make e1-4-summarize  # regenerates summary.csv, per_attack_eer.csv, feature_probes.csv, RESULTS.md
make e1-4-trim       # bonafide silence-trimmed attribution
# or the first four:
make e1-4
```
